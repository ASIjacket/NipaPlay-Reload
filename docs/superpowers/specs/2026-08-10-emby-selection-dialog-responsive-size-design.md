# Emby 版本选择弹窗响应式尺寸设计

## 目标

缩小 Windows 上的 Emby“版本与轨道”弹窗，并让它随可用窗口尺寸变化。iOS 底部面板及其他通用窗口不受影响。

## 尺寸规则

- 弹窗最大宽度取屏幕宽度的 `72%`，并限制在 `680–860px`。
- 弹窗最大高度以屏幕高度的 `78%` 为目标，并限制在 `560–760px`；在较矮窗口中不得超过现有窗口脚手架的安全区域。
- 内容宽度低于 `720px` 时，沿用现有布局规则，从左右双栏自动切换为上下单栏。
- 大屏不继续放大，小屏优先保证弹窗可见和内容可滚动。

## 实现范围

只在 `showEmbyMediaSelectionDialog` 中依据 `MediaQuery` 计算传给 `NipaplayWindowScaffold` 的 `maxWidth` 和 `maxHeightFactor`。不修改通用脚手架，不改变媒体选择、保存或播放逻辑。

尺寸计算提取为纯函数，方便覆盖常见桌面分辨率和边界值。

## 验证

- 单元测试验证宽屏、普通窗口和小窗口的宽高上下限。
- 现有 Windows 弹窗交互测试继续通过。
- 现有 iOS sheet 测试继续通过，证明本次修改没有影响移动端容器。
